# Escuela UC Villa Alemana — Sitio web profesional

Versión rediseñada con estética institucional. Preparada para GitHub Pages y VS Code + Live Server.

## Archivos
- `index.html`: contenido, secciones y enlaces.
- `styles.css`: estilo visual (azul marino, tipografía, tamaños y responsive).
- `script.js`: menú móvil.
- `assets/escudo-cduc-original.png`: escudo CDUC extraído de la tercera imagen proporcionada, conservando el diseño y con fondo exterior transparente.
- `assets/escuela-uc.png`: escudo circular de la filial.
- `assets/*-poster.webp`: afiches oficiales proporcionados por el usuario.

## Cómo verlo en VS Code
1. Abre la carpeta descomprimida con VS Code.
2. Instala la extensión **Live Server** de Ritwick Dey.
3. Abre `index.html` con **Open with Live Server**.
4. Guarda los cambios con Ctrl+S: el navegador se actualizará.

## Cómo actualizar GitHub
1. Descomprime el ZIP.
2. Sube `index.html`, `styles.css`, `script.js`, `.nojekyll` y la carpeta `assets/` al **directorio raíz** del repositorio.
3. En GitHub Pages configura la rama `main` y la carpeta `/ (root)`.
4. Si el repo contiene un antiguo `Escuela.html`, no lo uses como principal.
